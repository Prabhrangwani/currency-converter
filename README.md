# Currency Converter 🌍

A Python command-line tool that converts currencies in real time 
using live exchange rates and displays a 30-day historical trend chart.

## Features
- Live exchange rates via open.er-api.com
- Supports all major world currencies
- Visual 30-day trend chart using matplotlib

## How to Run

1. Clone this repo
   git clone https://github.com/prabhrangwani/currency-converter.git

2. Install dependencies
   pip3 install requests matplotlib

3. Run the program
   python3 converter.py

## Example
   From currency: USD
   To currency: CAD
   Amount: 100
   100 USD = 136.5 CAD
